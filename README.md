# Clinical Prediction Modelling Practice Project: Predicting Motor Outcome Using Simulated DBS-Style Data

## Project summary

This project demonstrates a beginner-friendly, reproducible R workflow for clinical prediction modelling using simulated DBS-style data. It focuses on understanding modelling structure and interpretation rather than producing real clinical findings.

## Project aim

This independent methodological project was developed to practise a reproducible R-based workflow for clinical prediction modelling in a DBS-relevant context. 

This project is intended as a methodological learning exercise. It does not use real patient data and does not make clinical claims about DBS outcomes. The project uses a simulated clinical-style dataset containing demographic, motor, neuropsychological, mood, and imaging-derived proxy variables, and applies regression-based approaches to predict simulated motor improvement following subthalamic deep brain stimulation.

## Why simulated data were used

Real DBS datasets are typically sensitive, specialised, and not publicly available without appropriate governance, ethics approval, and clinical collaborations. To avoid overstating access to clinical data, this project uses clearly labelled simulated DBS-style data.

The simulated dataset was designed to resemble the structure of a clinical prediction dataset, including variables such as age, disease duration, baseline UPDRS-III score, levodopa responsiveness, MoCA score, mood symptoms, and imaging-style proxy measures.

## Simulated variables

The simulated dataset includes:

- Age
- Sex
- Parkinson’s disease duration
- Baseline UPDRS-III motor score
- Levodopa responsiveness
- MoCA cognitive screening score
- Depression/anxiety symptom score
- Simulated STN connectivity score
- Simulated electrode distance proxy
- Simulated percentage motor improvement after DBS
- Simulated responder status

## Methods

The workflow includes:

1. Simulation of a DBS-style clinical dataset.
2. Introduction of a small amount of missing data.
3. Missing data inspection.
4. Descriptive summary of variables.
5. Complete-case analysis for this beginner project.
6. Train-test split.
7. Baseline linear regression model.
8. Penalized regression using LASSO.
9. 10-fold cross-validation for LASSO penalty selection.
10. Model performance evaluation using RMSE, MAE, and R-squared.
11. Visualisation of predicted versus observed outcomes.
12. Cautious interpretation of model coefficients.

## Results summary

The project successfully demonstrates a complete beginner-friendly prediction modelling workflow in R. The baseline linear regression model and LASSO regression model were compared using test-set prediction metrics.

Because the dataset is simulated, model coefficients and performance estimates should not be interpreted as clinically meaningful. The results are useful only for demonstrating the modelling workflow, including preprocessing, regression, penalized regression, cross-validation, and transparent reporting.

## Limitations

This project has several important limitations:

- The dataset is simulated and does not represent real DBS patients.
- The relationships between predictors and outcome were generated by the simulation process.
- The sample size is small.
- Missing data were handled using complete-case analysis, which may be inappropriate in real clinical datasets.
- The imaging variables are simplified proxies and do not represent real neuroimaging processing.
- No external validation was performed.
- The project should not be interpreted as original DBS outcome research.
